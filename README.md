# Thomas Livon - Portfolio Personal

¡Bienvenido al repositorio de mi sitio web de portfolio personal! Este sitio web muestra mi trabajo, habilidades y experiencia como desarrollador.

## 🌟 Características

- **Diseño Responsivo**: Sitio web completamente adaptable que funciona en todos los dispositivos
- **Tema Claro/Oscuro**: Funcionalidad de cambio de tema para una mejor experiencia de usuario
- **Interfaz Moderna**: Diseño limpio y moderno con animaciones suaves
- **Secciones Interactivas**:
  - Sección principal con fondo dinámico de estrellas
  - Sección Sobre Mí con información personal
  - Muestra de proyectos
  - Visualización de habilidades
  - Pie de página con enlaces sociales

## 🛠️ Construido Con

- **React** - Framework de frontend
- **Vite** - Herramienta de construcción
- **ESLint** - Linting de código
- **CSS Moderno** - Estilos
- **Componentes UI Interactivos** - Notificaciones toast personalizadas y más

## 🚀 Comenzando

### Requisitos Previos

- Node.js (v14 o superior)
- npm o yarn

### Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/Thlivon/portofolio.git
```

2. Instalar dependencias

```bash
npm install
# o
yarn install
```

3. Iniciar el servidor de desarrollo

```bash
npm run dev
# o
yarn dev
```

4. Abrir [http://localhost:5173](http://localhost:5173) en tu navegador
